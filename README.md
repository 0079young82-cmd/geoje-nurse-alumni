# 거제대학 간호과 동문회 · 임원 인계 의견함

2026년 임원단 인계를 위해 회원들이 휴대폰으로 의견을 내는 웹 앱입니다.

- **회원 화면**: 회칙 개정안 찬성·반대·보류, 감사 2명·차기 회장 추천, 회계 내역 확인과 질문, 제출
- **회장 화면** (`주소#admin`, 비밀번호로 접속): 실시간 취합 결과, 질문 답변 공개, 회계 내역·개정안·안내문 수정, 결과 요약 복사, 엑셀(CSV) 내려받기
- 모든 응답은 회장님 구글 스프레드시트에도 한 줄씩 쌓입니다.

화면은 GitHub Pages가 보여주고, 저장은 구글 스프레드시트가 맡습니다. 둘 다 무료입니다.

---

## 1단계. 구글 스프레드시트 저장소 만들기 (10분)

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 `동문회 의견함`으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 원래 있던 코드를 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
4. 맨 위의 `const ADMIN_PASSWORD = '여기에-회장님-비밀번호';`에서 따옴표 안을 **회장님만 아는 비밀번호**로 바꾸고 저장(💾)합니다.
5. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴에서 유형 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 구글 계정 권한 허용("고급 → 안전하지 않은 페이지로 이동"이 나오면 본인이 만든 스크립트이므로 진행)
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.

> 나중에 Code.gs를 고쳤다면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로입니다.

## 2단계. GitHub에 올리기 (10분)

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
   - 이름 예: `geoje-nurse-alumni`, **Public** 선택 → Create repository
2. **uploading an existing file**을 눌러 이 폴더의 파일을 모두 끌어다 놓고 **Commit changes**를 누릅니다.
   (`index.html`, `app.js`, `style.css`, `config.js`, `README.md`, `apps-script` 폴더)
3. 저장소에서 `config.js`를 열고 ✏️(연필)을 눌러 따옴표 안에 1단계의 웹 앱 URL을 붙여넣은 뒤 **Commit changes**를 누릅니다.
   ```js
   window.GJ_API = "https://script.google.com/macros/s/…/exec";
   ```
4. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 Save를 누릅니다.
5. 1~2분 뒤 화면 위에 나오는 주소(`https://아이디.github.io/geoje-nurse-alumni/`)가 앱 주소입니다.

## 3단계. 공개 전 준비

1. 앱 주소 뒤에 `#admin`을 붙여 열고(`…/geoje-nurse-alumni/#admin`), 비밀번호로 들어갑니다.
2. 아래쪽 **공개되는 내용 고치기**에서
   - 개정안 5건 문구를 확인하고 확정합니다.
   - 마감일을 정합니다. 기본값은 11월 30일입니다.
   - 회계 내역은 11월 13일 나이팅게일 선서식 화환 지출 후 입력합니다. 엑셀에서 `날짜 · 구분 · 내용 · 항목 · 금액 · 비고` 열을 복사해 한꺼번에 붙여넣을 수 있습니다.
3. 화면 맨 아래 **공개 내용 저장**을 누릅니다.
4. 회장님 휴대폰으로 시험 제출을 한 번 해보고, 취합 결과에 나오는지 확인한 뒤 명단에서 **삭제**합니다.
5. 앱 주소를 단체 카톡방에 올립니다.

## 알아둘 점

- 회원은 같은 **이름+기수**로 다시 제출하면 의견이 바뀝니다. 처음 정한 **4자리 비밀번호**가 맞아야 하므로 다른 사람이 대신 고칠 수 없습니다.
- 감사·회장 추천과 제출자 이름은 회장 화면과 스프레드시트에만 보입니다. 회계 질문은 답변을 달아 공개할 때 "OO기 동문 질문"으로만 표시됩니다.
- 스프레드시트의 `공개내용` 시트 A1 칸은 앱이 쓰는 칸이니 직접 고치지 마세요. `응답`, `회계내역` 시트는 자유롭게 보고 인쇄해도 됩니다.
- 회장 비밀번호는 Code.gs 안에만 있고, GitHub에는 올라가지 않습니다.
